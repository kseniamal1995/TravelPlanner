# Дизайн-система

Направление: **прохладный светлый минимализм** (v13; ранее «тёплый editorial»). Светлый воздушный фон, чернильный текст, **индиго как основной цвет действий**, серифные заголовки, большие радиусы, мягкие нейтральные тени, сдержанный моушн. Зелёный — только семантика «готово».

## Цвета (CSS-переменные `:root`)

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#F4F5F8` | фон (прохладный светлый) |
| `--card` | `#FFFFFF` | карточки |
| `--ink` | `#1C1E26` | основной текст; тёмные элементы (тост) |
| `--soft` / `--soft2` | `#6E727E` / `#A6AAB4` | вторичный текст / третичный |
| `--line` / `--line2` | `#ECEDF1` / `#DEE0E6` | рамки карточек / рамки контролов |
| `--acc` | `#5E5CE6` | **акцент-действие (индиго)**: CTA-пилюли, активный таб, чипы, фокус |
| `--acc-bg` | `#ECECFB` | подложка акцента: чипы-ссылки, иконные контролы, активная навигация |
| `--blue` | `#4F46E5` | текстовые ссылки (индиго чуть глубже; имя историческое) |

| `--amber` / `--amber-bg` | `#9A6A12` / `#F7F0E1` | билеты к покупке, предупреждения о часах |

Правила: **чёрных кнопок нет**; **основной цвет = индиго `--acc`, зелёный `--green` зарезервирован под «готово/успех»** (не использовать как action); **цветная заливка — только у семантики** (готово / билет / опасность), категория-бейдж и разделители частей дня — серый текст без подложки; **одна залитая индиго-кнопка на экран**; один «кружок» индикатора нагрузки — точка на табе; нейтральные подложки — только не-интерактивным элементам (инпуты всегда белые). Тёплый вторичный `--terra` удалён (v15).

## Типографика

- **Display**: `Source Serif 4` (Google Fonts, кириллица) — h1–h3, названия поездок, даты в табах.
- **UI/текст**: `Onest` (Google Fonts, кириллица) — всё остальное.
- **Шкала весов** (введена против «всё жирное»): `400` обычный текст (описания, детали, lead) · `500` мета, бейджи, подписи · `600` чипы, лейблы модалок, перегоны · `700` названия мест, кнопки · `800` только display-заголовки.
- Размеры: h1 30–34, названия мест 16.5, описание 14 (line-height 1.55), мета 13–13.5, чипы/бейджи 12–12.5, подпись таба 10.5.

## Формы

- Радиусы: карточки мест/блоки 20, карточки напоминаний 18, табы 15, превью мест 14, шиты 26 (верх) + grabber-ручка, нижняя навигация 22, **все кнопки и чипы — пилюли (999)**.
- Карточки: белые, **без рамок** — только мягкая нейтральная тень `--shadow-card` на тонированном фоне; раскрытая — `--shadow-card-lg`.
- **Табы дней**: пилюли `--pill-bg`, активный — подложка `--acc-bg` с индиго-текстом; `flex: 1 0 auto` — тянутся на всю ширину, при 10+ днях ряд скроллится; таб «+» (добавить день) — фиксированная пилюля с иконкой plus.
- **Строка дня**: слева чип-кнопка «Маршрут в Google Maps» (`--acc-bg` + индиго, иконка + текст), справа описание дня: точка-легенда нагрузки (8px, цвет `--dot-*`) + «Средний день · 9 мест · погода».
- **Перетаскивание карточек**: ручка = превью места (фото), `touch-action: none`; перетаскиваемая карточка — `--shadow-card-lg`, цель — индиго-линия `.dropline` 3px.
- **Бейдж категории**: без подложки — иконка 12 + серый текст 12/500. Цветные плашки — только семантика.
- **Бейдж билета на карточке**: круглый 28px справа у шеврона — `--amber-bg` «нужен билет» / `--green-bg` «куплен»; скрыт при отказе от билета (`skipTk`). Шеврон карточки — по центру высоты справа.
- Отступы: единый ритм 4/8/12/16/24 — между карточками 12, внутри карточки 16, разделители частей дня 28 сверху.
- **Строка-подложка `.inforow`** (паттерн «строка → модалка»): белая подложка с 3D-иконкой, заголовком, чипом и шевроном; по тапу открывает bottom-sheet. Используется для «Прибытие и заселение» (в модалке — детали + поля времени прилёта/вылета/заселения).
- Тач-таргеты ≥ 44px (кнопки, селекты, чекбоксы — увеличенные хит-зоны).
- Модалки: bottom-sheet, max-width 640, заголовок отделён от контента (margin 16), белые инпуты с рамкой `--line2` и индиго focus-кольцом (`box-shadow 0 0 0 3px --acc-bg`); секции-блоки (прибытие/отъезд) — тонированные `--bg`, без рамок.

## Иконки

Единая inline-SVG библиотека в стиле Lucide: словарь `PATHS` + хелпер `ic(name, size)`. ViewBox 24, `stroke-width:2`, `currentColor`, скруглённые концы. Размеры: 12–13 в статусах/чипах, 14–15 в кнопках, 17–20 в шапках/навигации, 30 в пустых состояниях.

Состав (~30): ext, chev/chevl/chup/chdn, pen, trash, plus, settings, bell, bulb, pin, route, ticket, clock, warn, check, note, walk, train, bus, car, bed, landing, plane, moon, sun, coffee, cloud, rain, bag, food, bookmark, sparkles, landmark, leaf, camera, dots.

**Цветные 3D-иконки (Microsoft Fluent Emoji 3D, MIT):** для контент-акцентов — плитки-превью мест без фото и иконка строки прибытия. Self-hosted PNG в `public/emoji/<cat>.png`, маппинг категория→иконка задаётся в `src/data/badges.js`. Line-иконки (`ic()`) остаются для интерфейса (навигация, контролы, шевроны, мелкие бейджи), 3D — только крупные акценты (≥36px), где они читаются.

**Эмодзи в тексте разрешены только в контенте** (названиях мест) — это характер данных, не интерфейс. С v17 эмодзи еды (🥐 ☕ 🍜) из названий убраны — дублировали бейдж категории; единичные характерные (⭐ концерт, 🎭 опера) остаются.

## Моушн (всё CSS, отключается `prefers-reduced-motion`)

| Анимация | Где | Параметры |
|---|---|---|
| Стаджер-появление | карточки при смене дня/экрана | rise 10px, .34s, шаг 28ms (cap 8), `--d` через inline-style; класс `.anim` на контейнере ставится только при навигации |
| Выезд шита | модалки | translateY 48px → 0, .32s, лёгкий овершут + фейд подложки |
| Нажатие | все кнопки/карточки | scale(.96–.985), .13s |
| Чек-поп | «Билет куплен», «посещено» | scale 0→1.25→1, .28s overshoot |
| Поп таба | активация дня | scale .92→1, .18s (только при `.anim`) |
| Навигация | активный пункт | подложка-пилюля + подъём иконки 1px |
| Тост | появление | пружинная кривая `cubic-bezier(.3,1.4,.4,1)` |
| Раскрытие карточки | grid-rows 0fr→1fr + фейд содержимого + поворот шеврона | .28s |
| Вспышка | только что добавленное место | фон `--acc-bg` → white, 1.4s |

## Перенос в Telegram

При переходе на TMA маппить токены на `themeParams` Telegram (тёмная тема), сохранив семантические роли. Серифные заголовки и зелёный акцент — элементы бренда, их сохраняем поверх темы.
