# Модель данных (schema v14)

## Хранилище

- Ключ: `trip-planner:v2`, значение — JSON всего состояния.
- Прототип: `window.storage` (среда артефакта) с fallback в память (`mem`). В обычном браузере (file://) состояние живёт до перезагрузки — это ожидаемо для прототипа.
- Запись — на каждое изменение (`save(S)` после каждой мутации); заметки сохраняются на каждый ввод.
- Для TMA: заменить на **адаптер хранилища** (см. `06-telegram-migration.md`, там же про лимиты CloudStorage).

## Схема

```js
S = {
  version: 14,
  activeCity: 'paris' | null,        // null = главная
  cities: { [cityId]: City }
}

City = {
  id, name,                          // 'paris', 'Париж'
  tripStart: '2026-07-02',           // ISO-дата первого дня (дни считаются от неё)
  walk: 'low'|'med'|'high',          // темп ходьбы (только в seed; из UI убран в v15, читает intensity)
  arrival: '10:35', departure: '18:20', checkin: '16:00',   // HH:MM
  food: 'none'|'snack'|'resto',      // legacy: нигде не читается, из UI убран в v15
  arrivalDay: 'd2',                  // id дня прилёта (рендерит блок прибытия)
  hotel: { name, addr, metro, gmaps } | null,
  orly: '<html>',                    // дорога аэропорт→отель (HTML) — блок «Дорога до отеля» в модалке прибытия
  orlyOut: '<html>',                 // дорога отель→аэропорт (HTML) — модалка «Отъезд» (строка на последнем дне)
  departureNote: '…',                // подсказка по таймингу выезда (модалка «Отъезд»)
  reminders: [ { id, text, due:'YYYY-MM-DD'|'', url?, done } ],
  days: [ Day ],                     // порядок = порядок дней
  activeTab: 'd2',                   // открытый день
  places: [ Place ]
}

Day = {
  id: 'd2',                          // уникальный, не индекс!
  mode: 'walking',                   // travelmode для ссылки Google Maps
  first: { m, t, to } | null,        // перегон отель→первая точка
  theme: 'Музеи · Еда'               // выбранные темы дня (в UI не показывается; вход для движка)
}

Place = {
  id, bucket,                        // bucket: id дня | 'shop' | 'food' | 'later'
  name, rating: '4,6'|'',            // рейтинг строкой (запятая)
  cat: 'sight'|'museum'|…,           // категория-бейдж под названием (список — src/data/badges.js); фолбэк 'other'
  pri: 'must'|'want'|'opt',          // приоритет (только в seed; новым местам не проставляется, в UI нет)
  rname: 'Louvre Museum, Paris',     // имя для геокодирования в маршруте
  wiki: 'Лувр',                      // заголовок статьи ru.wikipedia для фото (опц.)
  desc, gmaps,                       // описание; прямая ссылка на Google Maps
  visit: '~3 ч',                     // время на осмотр (парсится intensity())
  leg: { m:'walk|metro|bus|car', t:'8 мин', to:'…' },  // перегон ДО СЛЕДУЮЩЕЙ точки
  ticket: { price, lead, url },      // цена, подсказка о сроках брони, сайт
  warnH: '…', warnS: '…',            // предупреждения: часы работы / безопасность
  booked: 1, bt: 'пт 9:30',          // забронировано (+ когда) — задаётся данными
  rec: 1,                            // рекомендация приложения (пока не в UI)
  nort: 1,                           // не включать в маршрут Google Maps
  sect: { ic:'moon|sun|coffee|plane', t:'Вечер · концерт', note:'…' },  // разделитель части дня ПЕРЕД этим местом
  // — пользовательские поля (переживают миграции): —
  bought: false,                     // билет куплен (тоггл)
  skipTk: false,                     // осознанный отказ от билета («смотрю снаружи»)
  userNote: '',                      // заметка
  done: false,                       // «посещено» (чек-офф; UI отключён в v16, код закомментирован)
  order: 0                           // порядок внутри bucket
}
```

## Производные данные (не хранятся)

- **Даты дней**: `dayLabel(tripStart, index)` → «2 июля», «Чт». Удаление/добавление дня автоматически сдвигает даты последующих.
- **Насыщенность дня** `intensity()`: `score = пешие_минуты + минуты_осмотра×0.6 + точек×8`, делится на коэффициент темпа (high 1.3 / med 1 / low 0.8). Уровни: `<150` лёгкий, `<290` средний, иначе насыщенный. Км ≈ `пешие_минуты/60 × 4.5`. Места с `nort` не считаются.
- **Маршрут дня** `routeUrl()`: Google Maps Directions deep-link по `rname` точек дня (сортировка по `order`, без `nort`), `travelmode` из `day.mode`.
- **Прогресс дня**: `done`-места без `nort` / всего точек (UI отключён в v16 вместе с чеком «посещено»).

## Миграции

При `stored.version < seed.version` состояние пересобирается из нового seed с переносом пользовательского:

1. По каждому месту (ключ `cityId::placeId`): `bought`, `skipTk`, `userNote`, `done`.
2. По каждому напоминанию: `done`.
3. Места пользователя, которых нет в seed (добавленные вручную), переносятся целиком.
4. Города, которых нет в seed (созданные пользователем поездки), переносятся целиком.

⚠️ Правки seed-полей применяются только через bump версии. Пользовательские структурные изменения seed-города (перенос мест между днями, изменение тем) при миграции **сбрасываются** — известное ограничение прототипа; в проде сервер хранит каноничное состояние пользователя и миграции делаются по-другому.

## Сторонние данные в состоянии

Seed Парижа (5 дней, 34 + 11 мест, 4 напоминания) — одновременно демо и эталон «человеческого» маршрута: якоря дней, варианты A/B, день прилёта/отъезда, разделители частей дня, билеты с дедлайнами брони. Использовать его как референс качества при разработке движка.
