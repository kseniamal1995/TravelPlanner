# Функциональность — полный инвентарь

Четыре экрана: **Главная** → **Поездка (план)** ⇄ **Идеи** ⇄ **Напоминания** (последние три связаны нижней навигацией). Модальные окна — bottom-sheets c grabber-ручкой.

## 1. Главная

- Заголовок «Маршруты» (сериф) + кнопка «Напоминания» (все поездки, read-only).
- **Карточка поездки**: название (сериф), диапазон дат, число дней, число мест в плане, **стопка из ≤4 круглых фото-превью мест**. Тап → план поездки.
- «+ Новая поездка» → шит: город, дата первого дня, число дней (number), отель (опционально; потом редактируется в модалке «Прибытие и заселение»). Создаёт пустые дни, `arrivalDay` = первый день.
- Пустое состояние: иконка-круг + «Пока нет поездок».

## 2. Поездка — план по дням

### Шапка
- «← Поездки», название города (сериф). Кнопки настроек **нет** — шиты «Настройки поездки» и «Настроить день» отключены в v16 (файлы-наработки: `sheets/tripSettings.js`, `sheets/daySheet.js`).
- Подзаголовок: счётчик мест (`33 места`); число дней видно по табам.

### Табы дней
- Дата (сериф) + день недели, авто-расчёт от `tripStart`; пилюли `--pill-bg`, активный — подложка `--acc-bg` с индиго-текстом.
- **Ширина**: табы тянутся на всю ширину ряда (`flex: 1 0 auto`); при 10–14 днях не сжимаются ниже контента — ряд скроллится горизонтально. При скролле края ряда мягко растворяются (CSS-mask; классы `fadeL/fadeR` ставит render.js по `scrollLeft`).
- **Точка нагрузки** в углу таба: 🟢/🟠/🔴 по `intensity()`; расшифровка уровня — в строке дня.
- **Таб «+»** в конце ряда — добавляет пустой день и открывает его.
- **Удаление дня** — тихая красная текст-кнопка «Удалить день»: внизу ленты дня (справа от «Добавить место») и в пустом дне под CTA. Места уходят в «На потом», тост с undo; единственный день удалить нельзя (кнопка скрыта).

### Блок дня
- **Строка дня** под табами: слева кнопка-чип **«Маршрут в Google Maps»**, справа описание дня — `[погода] ● Средний день · 9 мест` (точка-легенда того же цвета, что и на табе — расшифровывает индикатор нагрузки). Погода появляется, когда дата в пределах прогноза (см. 05-architecture).
- Маршрут — пеший по точкам дня: origin = первая точка, waypoints, destination = последняя; места с `nort:1` исключаются; кнопка скрыта, если точек < 2.
- `day.theme` в UI не показывается (описания дней убраны) — хранится как вход для будущего LLM-движка.
- **День прилёта** (`arrivalDay`): строка «Прибытие и заселение» показывается **всегда** — это единственная точка редактирования отеля и времён прилёта/вылета/заселения. В модалке: Перелёт (прилёт + вылет), Дорога до отеля (`city.orly`, если есть), Заселение (инпут «Отель» + «Заселение с» + ссылка на карты).
- **«Старт»**: серая плашка с перегоном `day.first` до первой точки — только если у дня задан нестандартный старт.
- **Разделители частей дня** (`place.sect`): волосяные линии + нейтральный серый микро-лейбл с иконкой (`Вечер · концерт`, `Вариант A · прогулка`) + опциональная заметка-инструкция (вернуться в отель, тайминг выезда).
- **Перегоны** между картами: серые плашки `[иконка транспорта] 8 мин`.
- «+ Добавить место» (индиго пилюля — единственная залитая кнопка экрана).
- **Пустой день**: компактная иконка-круг + «День пока пуст» + CTA «Добавить место» + «Удалить день».

### Карточка места (свёрнута по умолчанию)
Свёрнутый вид:
- **Превью 48×48**: фото из Wikipedia (если есть `wiki`) или плитка с 3D-иконкой категории. **Превью = ручка перетаскивания**: потянув за фото, карточку можно переставить в списке (индиго drop-индикатор; `src/ui/drag.js`; порядок пишется в `order`).
- Название; **мета-строка**: категория (иконка + серый текст без подложки) · рейтинг `★ 4,6` (серый) · иконки ⚠ (безопасность, красная, 15px) и 📝 (есть заметка).
- **Справа по центру высоты**: **бейдж билета** (круглый: янтарный 🎟 = нужен билет / зелёный 🎟 = куплен-забронирован; скрыт при «без билета») + шеврон (поворачивается при раскрытии).
- Чек «посещено» **отключён в v16** (код закомментирован в stop.js / events.js / plan.js — наработка сохранена).
- Текстовых статусов и цен на свёрнутой карточке нет — каждый факт ровно в одном месте на каждом уровне.

Развёрнутый вид (тап по карточке; тап по интерактивным элементам не сворачивает):
- Длительность осмотра; бейдж «✓ Забронировано · пт 9:30» (если `booked`; цена скрыта).
- Описание, предупреждения (часы — янтарная плашка, безопасность — красная).
- **Блок билета** (единый статус): чип цены + кнопка-тоггл «Билет куплен?» + текстовая кнопка **«Не покупать»** (`place.skipTk` — «знаю, что нужен билет, но пройду рядом»; состояние: «🎟 Без билета — смотрю снаружи» + «Нужен билет» для возврата) + чип-ссылка «Билеты» + строка-подсказка о сроках брони.
- Заметка пользователя (плашка), компактный чип-ссылка «Google Maps».
- «Изменить» → textarea заметки (автосохранение при вводе), select «перенести» (дни по датам + разделы идей), удаление (мгновенно + тост с undo). Сортировка вернётся drag-handle'ом в TMA.

### Шиты настроек — отключены (v16)
- **«Настроить день»** (`sheets/daySheet.js`: темы дня, «взять из идей», «удалить день») и **«Настройки поездки»** (`sheets/tripSettings.js`: степпер дней, отель) выключены из UI; файлы сохранены как наработки для будущего редактора дня.
- Их функции переехали: день добавляется табом «+», удаляется кнопкой внизу ленты дня; отель — при создании поездки и в модалке «Прибытие и заселение»; взять отложенные места — чек-лист «Или взять из идей и „На потом“» в шите **«Добавить место»**; перенос — селектом «перенести» на карточке. Темы дня временно недоступны.

## 3. Идеи
- Под-вкладки: Шопинг / Еда / На потом (те же карточки мест).
- «На потом» — также приёмник мест из удалённых дней.
- Перенос в день: select «перенести» в карточке («Изменить») или чек-лист в шите «Добавить место» на странице дня.

## 4. Напоминания
- **Из поездки** (нижняя навигация): только её напоминания, есть «+ Напоминание» (текст + крайняя дата).
- **С главной**: все поездки, подпись города на карточке, read-only.
- Карточка: чекбокс «сделано», заголовок = первое предложение, остальное по тапу (шеврон), чип дедлайна (просрочено — красный / ≤14 дней — янтарный «через N дней» / иначе дата), чип-ссылка «Открыть».
- Сортировка по дедлайну.

## 5. Сквозное
- **Undo-система**: удаление места, добавление дня — мгновенно + тост/снапшот «Отменить» (5 сек, восстанавливает полный снапшот состояния).
- **Подсветка нового места**: после добавления карточка вспыхивает акцентным фоном.
- **Нижняя навигация** (внутри поездки): План / Идеи / Напоминания, активный пункт — индиго-пилюля.
- **Микроанимации** (все CSS, отключаются `prefers-reduced-motion`): стаджер карточек при смене дня/экрана, выезд шитов, scale-нажатия, чек-поп «Билет куплен», поп активного таба, подъём иконки в навигации, пружинный тост, фейд содержимого карточки, вспышка нового места.
- **Числительные**: все склонения через `plural()` (день/дня/дней, место/места/мест, точка/точки/точек).
