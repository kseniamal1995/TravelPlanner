## Мини-глоссарий

- **bucket** — куда отнесено место: id дня (`d2`…) или раздел идей (`shop` / `food` / `later`).
- **leg** — перегон до следующей точки: `{m: walk|metro|bus|car, t: '8 мин', to: 'описание'}`.
- **first** — перегон «отель → первая точка дня».
- **sect** — разделитель части дня перед местом: `{ic, t, note}` («Вечер · концерт»).
- **nort** — место не включается в пеший маршрут Google Maps (концерт, обед, логистика).
- **pri** — приоритет места: `must | want | opt` (пока не визуализирован — в бэклоге).
- **rec** — место предложено приложением, а не пользователем (пока не визуализирован — в бэклоге).
