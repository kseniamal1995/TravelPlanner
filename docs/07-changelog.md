## v17 — итерация 7: строка дня, drag&drop, табы (2026-06-10)

_Schema bump v14 → v15: из названий мест категории «еда» убраны эмодзи (🥐 ☕ 🍽 🥖 🍜) — дублировали бейдж категории._

- **Описание насыщенности вернулось**: строка дня = «Маршрут в Google Maps» слева, справа — `[погода] ● Средний день · 9 мест`; точка-легенда того же цвета, что индикатор на табе (расшифровывает «непонятные цветные точки»).
- **Перетаскивание мест**: ручка = превью карточки (фото); подъём карточки + индиго drop-индикатор; порядок сохраняется в `order`. Работает в днях и в идеях (`src/ui/drag.js`; нативный drag `<img>` подавлен).
- **«Взять из отложенных» вернулось** — чек-лист «Или взять из идей и „На потом“» в шите «Добавить место» (бывший функционал шита дня; один вход для добавления чего угодно в день).
- **Табы дней — резиновые**: `flex: 1 0 auto` — заполняют всю ширину ряда без пустого хвоста справа; при 10–14 днях не сжимаются ниже контента, ряд скроллится.
- **Края ряда табов растворяются при скролле** (CSS-mask, классы `fadeL/fadeR` от `scrollLeft`) — табы больше не «выезжают» жёстко за край контента.
- **Удаление дня вернулось**: тихая красная текст-кнопка внизу ленты дня и в пустом дне; места — в «На потом», тост с undo; единственный день не удалить.
- **Пустой день компактнее**: иконка 72 → 54, CTA — обычная пилюля вместо большой, текст 400 веса, отступы меньше.
- **Отступы в шапке дня** увеличены (табы/строка дня/прибытие — ритм по референсам).
